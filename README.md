# FeedMe MVP

A mobile-first Nigerian-focused meal recommendation MVP.

## Included
- Red/white Nigerian-focused landing page
- Sign-in entry flow (device-local MVP session)
- Back/sign-out navigation
- Household-friendly food stock tracking
- Nigerian meal variety
- Stock-aware recommendations
- Store-Only, Quick and Budget modes
- Recipe view
- Mark as cooked
- Automatic stock depletion for matching ingredients
- 1–5 star feedback
- Cooking history
- Local persistence via localStorage

## Run locally
Open `index.html` in a modern browser, or serve this folder with a simple static web server.

## Production note
This is a frontend MVP. Production authentication (SMS OTP/Google), cloud database, server-side security, analytics and multi-device sync require backend services.
